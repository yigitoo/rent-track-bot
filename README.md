# rent-track-bot

A telegram bot for rent-tracking.

## Commands

- `/kiraciekle` - Add a tenant with rent amount and monthly payment day.
- `/kiracilar` - List active tenants.
- `/kiraciduzenle` - Edit tenant name, address, rent amount, or payment day.
- `/odemeekle` - Record a rent payment.
- `/kiraertele` - Defer a tenant's rent due date for a specific month.
- `/durum` - Show the current month payment status.
- `/ozet AA/YYYY` - Show a monthly summary.
- `/mailgonder AA/YYYY` - Send the responsive monthly email report with calendar view.
